# Project 1: Customer Churn Analysis

## 📊 Project Overview
Predictive analytics project to identify customers likely to churn using machine learning.

## 🛠️ Technologies Used
- Databricks Community Edition
- PySpark
- Machine Learning (Logistic Regression, Random Forest)
- Python (pandas, matplotlib, seaborn)

## 📁 Dataset
- Synthetic customer data (1000 records)
- Features: Gender, Age, Tenure, Monthly Charges, Contract Type, etc.

## 🎯 Key Results
- Random Forest Accuracy: 85%
- AUC-ROC Score: 0.89
- Top churn predictors: Tenure, Contract Type, Monthly Charges

## 🚀 How to Run
1. Upload notebook to Databricks Community Edition
2. Create a cluster
3. Run all cells
4. View results and visualizations

## 📈 Skills Demonstrated
- Data preprocessing with PySpark
- Feature engineering
- ML model training and evaluation
- Data visualization
- Business insights extraction
